# muse-worstfix-entry

Entry for the make.fun competition [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

## The entry

> fix: remove the one comment that was apparently holding the whole system together

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: Reads exactly like a plain, tired commit subject, and the irony is specific to a repair: the 'fix' deleted a mere comment and the comment turned out to be load-bearing - a fresh angle away from the worn revert and test-in-production jokes.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 1ee71ce4d5b6a54b349195c45e9a71187c19cc8633699fd40c521dafb1b7f6cd).
